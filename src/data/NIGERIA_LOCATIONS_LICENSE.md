# Nigeria location data

Source: https://github.com/open-admin-data/nigeria-administrative-divisions

Derived from `data/all-state.json` and `data/all-lga.json`. Only English names are retained and the state/LGA options are sorted alphabetically. The dataset is bundled with the site; no visitor data is sent to the source provider.
